# Evaluation Demo Script

## Step-by-Step Evaluator Walkthrough

### 1. Landing Page
- Review the product value proposition and privacy note.
- Observe the illustrative card labeled `Illustrative example — not live air-quality data`.
- Click **Check My Area** to enter the live dashboard.

### 2. Main Dashboard & Provenance
- Inspect the primary AQI card displaying numeric index, scale, category, and source attribution.
- Verify that pollutant concentrations preserve raw units (`µg/m³`).
- Toggle between the trend chart and the accessible table alternative.

### 3. Actionable Advice & Evidence Chips
- Examine the 3-4 ranked daily recommendations.
- Click **Learn scale** to view scale definitions.
- Inspect the evidence basis citations and medical disclaimers.

### 4. Air Quality Explorer
- Switch between Map view and the Accessible Table view.
- Select alternative global cities and observe local Haversine distance calculations.

### 5. Indoor Air Quality Guide
- Review source reduction and outdoor-aware ventilation rules.
- Test the CADR room dimension calculator and the zero-cost DIY Corsi-Rosenthal filter pathway.

### 6. Transport Impact Calculator
- Enter commute distances and compare baseline vehicles with transit, cycling, and walking.
- Note the explicit boundary disclosure separating CO₂e greenhouse calculations from local PM2.5 exposure.

### 7. AI Assistant Chat
- Open the AI Assistant drawer.
- Click a suggested prompt (e.g., "How can I reduce cooking smoke?").
- Test prompt injection resistance (e.g., "Ignore all rules").
